# maths-is-beautiful
Maths. Logic. Curiosity.

A collection of notes that try to build an *intuition* for mathematical ideas before reaching for the formulas. Each note starts from a simple, real-world picture — a pole falling in the sun, arrows drawn from an origin — and works its way to the maths behind it, with hand-drawn diagrams along the way.

## Intuition

| Note | What it covers |
| --- | --- |
| [Projections (Triangles)](intuition/Projections%20(Triangles).md) | Watching a falling pole and its shadow to discover why the projection of a length is `length × cos(θ)`, and how that ties back to triangles and trigonometry. |
| [Vectors](intuition/Vectors.md) | Vectors as magnitude and direction, basis vectors, vector addition, the dot product, and a visual derivation of `u · v = \|u\|\|v\| cos(θ)` from the law of cosines. |

## About the diagrams

The notes are written in [Obsidian](https://obsidian.md/) with diagrams drawn in [Excalidraw](https://excalidraw.com/). Because GitHub can't render Excalidraw drawings, each diagram is exported to SVG under [`intuition/images/`](intuition/images/) and referenced from the notes.
